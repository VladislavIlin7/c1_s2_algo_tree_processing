Группа: М8О-102БВ-25

#### Постановка задачи:

Удлинение имен файлов до указанной длины заданным знаком.

#### Описание работ:

Создаем функцию, которая рекурсивно обходит указанный каталог и все вложенные подкаталоги. Скрипт принимает 3 аргумента:
путь к каталогу, нужную длину имени файла и символ, которым нужно дополнить имя.

Сначала проверяется количество аргументов. Затем проверяется, что переданный путь существует и является директорией,
длина является положительным целым числом, а знак заполнения состоит из одного символа. После этого путь к каталогу
преобразуется в абсолютный.

Для каждого найденного файла определяется имя без расширения и само расширение. Если имя короче указанной длины, к нему
справа добавляется заданный символ до нужной длины. Расширение файла сохраняется. Если файл с новым именем уже существует,
переименование не выполняется.

#### Запуск:

```commandline
./script.sh tests 6 _
```

Также можно посмотреть на параметры запуска, если запустить скрипт без аргументов:

```commandline
./script.sh
```

Вывод:

```text
Было введено 0 аргументов. Нужно 3 аргумента: <каталог> <длина> <знак>
```

